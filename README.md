# priorauth-agent

[![CI](https://github.com/26sneakysnake/priorauth-agent/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/26sneakysnake/priorauth-agent/actions/workflows/ci.yml)

## Synthetic data only

Every record in this repository is **100 % synthetic**: patients, names, identifiers, dates, providers and clinical
notes are generated by code with a fixed seed. No real patient data, no real clinical notes and no scraped medical
data are used anywhere.

## What this is

A prior-authorization agent for synthetic clinical records. An LLM agent extracts facts with cited evidence
(page + exact quote); a **deterministic** policy engine decides `APPROVE` or `PEND`. The code has no `DENY` outcome:
anything that is not fully met, verified and conflict-free goes to a human reviewer.

This README is hand-written while the project is being built and contains no measured numbers; it will be generated
from `results/` (`make readme`). Until then, the measured comparison of every system is
[`results/comparison.md`](results/comparison.md), itself generated from `results/*.json`; what it does not show is in
[`docs/LIMITS.md`](docs/LIMITS.md). Build status per phase: [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Demo

`make demo-up` starts the demo locally from its two Docker images (UI on http://localhost:3000, API docs on
http://localhost:8000/docs); the login page shows the public demo account. **The demo resets on every restart**:
it keeps its state in its container, seeded at start with ten labelled synthetic examples whose decisions come from
real model responses recorded once and replayed. Deployment: [`docs/DEPLOY.md`](docs/DEPLOY.md) (not deployed yet).

## Quick start

```bash
make setup   # uv sync --locked + pre-commit hook
make lint    # ruff + mypy --strict
make test    # pytest (every LLM call is replayed from eval/cassettes: no API key needed)
make gate    # regression gate on the replayed production agent
```
